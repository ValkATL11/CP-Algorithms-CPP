# Contributing

1. Open an issue or describe the problem being solved.
2. Add an implementation under the matching category.
3. Keep identifiers and code comments in English.
4. Add `README.md` and `README.vi.md` with matching technical content.
5. Document indexing, preconditions, complexity, limitations, and edge cases.
6. Add a focused `test.cpp`; include normal and boundary cases.
7. Compile with GNU++17 and warnings enabled.
8. Do not mark work as tested unless the test was actually executed.

Prefer a small, correct, reusable implementation over a broad but unverified template. Cite original papers or reputable references when an implementation depends on a specialized technique.
